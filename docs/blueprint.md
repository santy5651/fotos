# **App Name**: PicStack Local

## Core Features:

- Image Grid View: Display images in a responsive grid layout, sortable by date or name.
- Hierarchical Collections: Allow users to create hierarchical collections to organize photos.
- Multi-Collection Assignment: Enable adding photos to one or multiple collections for flexible organization.
- AI-Powered Tagging: Use Genkit to analyze and suggest relevant tags for uploaded images; use as a tool which user can edit later.
- Image Protection: Allow users to favorite and protect images with visual indicators on thumbnails.
- Data Export/Import: Enable exporting and importing of all images and metadata in a single file for backup and transfer.
- App Statistics: Display basic statistics in a modal: total images, images per collection in a simple chart.

## Style Guidelines:

- Primary color: Soft blue (#7EC4CF) to evoke a sense of calm organization.
- Background color: Light gray (#F0F4F5) for a clean and unobtrusive workspace.
- Accent color: Warm orange (#D68454) to highlight interactive elements and important actions.
- Clean and readable sans-serif font for all UI elements.
- Use clear and simple icons from Lucide React to represent actions and states.
- Responsive grid layout for image display; sidebar panel for collections navigation.
